# 端到端毕业任务（脱敏演示）

本演示不调用真实模型服务。它使用预设的结构化模型决策，在临时创建的受限工作区中修复一个故意写错的 `add` 函数。

## 覆盖的完整流程

1. 读取任务说明和源码。
2. 请求运行失败测试；执行前暂停并等待确认。
3. 根据失败结果提出精确的最小替换；执行前再次等待确认。
4. 请求复测；执行前第三次等待确认。
5. 仅在复测实际返回退出码 `0` 后，生成包含修改、验证、未解决风险和审计摘要的最终报告。
6. 保存会话和任务报告，使用新的 SQLite 存储实例模拟重启恢复。

## 安全边界

- 练习源码修改仅发生在临时受限工作区；工作区外的保护文件保持原样。
- 读取以外的测试与写入都要求一次性确认，确认令牌不会进入会话或持久化任务记录。
- 审计仅保留工具名称、调用标识和参数类型摘要，不保留任务正文、工具参数值或工具输出。
- 任务说明中的“未授权长期记忆”标记没有使用 `/remember`，因此重启后长期记忆仍为空。

## 复现方式

在项目虚拟环境中运行：

```bash
python -m pytest -q tests/test_graduation_demo.py
```

这是一份可重复、可分享的离线验收记录；不包含 API Key、个人路径、真实对话或模型请求。
